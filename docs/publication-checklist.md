# Publication checklist

This is the first source and documentation baseline. It is not the complete international competition submission.

## Included

- Current production package, hardware runner, and waypoint configuration.
- Current calibration and diagnostic tools relevant to that package.
- English overview covering hardware, architecture, control, setup, testing, and limitations.
- Existing English operating notes.
- Non-actuating repository consistency checks and a validation workflow.

## Required additions and verification

- [ ] Export the final bill of materials, dimensions, mass, mechanical models, and assembly instructions.
- [ ] Add wiring diagrams, main-board design/manufacturing material, and connector pinouts.
- [ ] Add vehicle photographs from front, rear, left, right, top, and bottom.
- [ ] Add a team photograph with permission for publication.
- [ ] Add accessible YouTube links demonstrating autonomous driving for each challenge, with at least 30 seconds of driving per challenge.
- [ ] Prepare the English engineering journal and the required hardcopy material.
- [ ] Export exact package versions, LiDAR driver revision, camera/PWM configuration, permissions, service, startup wrapper, and radio-mode helpers from the robot.
- [ ] Verify a fresh installation or document the remaining reproduction limitations.
- [ ] Implement and physically validate international parallel parking.
- [ ] Record legal-layout coverage, failure cases, recovery behavior, and performance with the tested software revision.
- [ ] Add completed modeling files and verification evidence when available; confirm any third-party publication permissions.
- [ ] Decide the license for team-owned source and retain applicable third-party notices.
- [ ] Confirm the organizer's repository submission deadline and the separate award application procedure.
- [ ] Review the final repository contents, make it public for submission, and retain public access for the required period.

Keep private correspondence, credentials, large raw run archives, obsolete duplicate drivers, and unrelated working documents outside the competition repository. Do not claim a planned feature or a desktop consistency check as a successful robot test.
