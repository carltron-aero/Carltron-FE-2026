# Measurement data

We use these selected results for the figures in [Testing and development](../../docs/testing/README.md). They include the failed and partial measurements needed for the comparisons. The [analysis guide](../../docs/testing/REPRODUCING.md) lists the runs and explains the reference points, timing and evaluation windows.

`render_figures.py` checks the data hashes and generates nine figures offline. Its plotting dependency is listed in `requirements.txt`. The hashes in `data/manifest.json` identify the saved analyses used here. The full sensor recordings, videos and newer robot test controllers remain in the separate development archive.
